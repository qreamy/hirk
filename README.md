# HIRK Sponsorportal v11

En renare och mer balanserad version av sponsorportalen med fokus på en enda tydlig desktopvy: kort sponsorinfo till vänster och intresseanmälan till höger.

## Start
1. Kopiera din befintliga `.env.local` till projektets rot.
2. Kör `npm install`.
3. Kör `npm run dev`.
4. Öppna `http://localhost:3000`.
